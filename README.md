# Madrasa System (React JS, no UI libraries)
1. Install Node.js, open this folder in a terminal
2. `npm install`
3. `npm run dev`  -> open the shown address
Login: head `admin` / `admin123` (change in Settings). Teachers are created in Settings.
Data is saved in the browser (localStorage). All school names, classes, fees, courses,
exams, rules, salary penalty are editable in Settings.
